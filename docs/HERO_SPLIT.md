# TRUST PROTOCOL: CRIMINAL LEGENDS — THE HERO SPLIT
## Main-Hero spine · Sub-Hero threads — a restructuring overlay for Campaign 2 "GREEN MEMORY"

**Status:** organisational overlay. It moves **no text** in
`SCENARIO_INTERCONTINENTAL_RING.md`; it re-labels ownership so every mission has
exactly **one lead** and the other two heroes serve as **sub-heroes**. Companion to
`BLOCKBUSTER_CUT.md` (which owns staging) — this document owns *billing*.

**The rule of three:** one hero carries the film, one hero carries the evidence,
one hero carries the laugh. No mission may have two leads. When all three are
required (ST-7, ST-12, ST-14, ST-15, ST-16, ST-18), billing rotates **per mission**,
never per scene.

**Lead privileges (apply in build and in writing):**
- The lead narrates the act's opening title card and closing button.
- The lead's portrait takes the act poster (see BLOCKBUSTER_CUT Part Five).
- The lead's signature mechanic defines the act's gimmick set: Film I = Green
  Ledger / terrain reading; Film II = INTERPRET / paperwork skill checks; Film III =
  Hatch Run / tails and verticality.
- Only the lead can trigger the act's **Trust fork** (the major ±Trust decision).

# 2. THE SUB-HERO ROLES (how the other two serve)

A sub-hero is never an escort. Each support role is a verb the lead cannot do:

# 5. WHAT THE SPLIT BUYS THE BUILD

1. **Roster pressure:** solo threads (ST-5, ST-17) and co-leads mean missions can
   bench heroes — the chronicle gains "absent from this page" lines, which cost
   nothing to write and read as legacy.
2. **Trust forks have a face:** every ±Trust decision lists its deciding hero in
   the UI ("Blackhujus decides"). Accountability is drama.
3. **Posters are pre-sold:** three films, three leads, three existing key arts —
   the BLOCKBUSTER_CUT poster table and this matrix now agree exactly.
4. **Sequel hook:** the split frees each hero for one tunnel node in the Next
   Episode (see `NEXT_EPISODE_TOP_SECRET_TUNNELS.md`, §Casting) — the matrix below
   is written so no hero ever leads two regions.
